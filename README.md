# 📊 Northwind: Dashboard de Rendimiento de Ventas y Catálogo de Productos

Análisis de datos empresariales utilizando la base de datos **Northwind**, integrando **SQL, Power Query, DAX y Power BI** para transformar datos transaccionales en indicadores y visualizaciones orientadas a la toma de decisiones.

---

## 🎯 Objetivo del proyecto

El objetivo es transformar información transaccional de **ventas, clientes y productos** en información útil para evaluar el desempeño comercial de la empresa.

El análisis busca responder preguntas de negocio relacionadas con:

- 📈 Evolución y crecimiento de las ventas.
- 💰 Ingresos y ticket promedio.
- 👥 Comportamiento y concentración de clientes.
- 🌎 Distribución geográfica de las ventas.
- 📦 Rendimiento de productos y categorías.
- 🚚 Desempeño y dependencia de proveedores.

La solución combina **SQL para extracción y análisis de datos** con **Power BI para modelado, métricas y visualización interactiva**.

---

## 🛠️ Herramientas utilizadas

| Herramienta | Uso |

| **Power Query** | Limpieza y transformación |

## 🔎 Preguntas de negocio

### 📈 Rendimiento y tendencias
- ¿Cómo evolucionan las ventas y qué períodos presentan cambios relevantes?
- ¿Cuál es el volumen de ventas, órdenes y ticket promedio?

### 👥 Clientes
- ¿Qué clientes generan mayores ingresos?
- ¿Existe concentración de ventas en pocos clientes?

### 📦 Productos y categorías
- ¿Qué productos y categorías tienen mayor desempeño?
- ¿Qué productos destacan por volumen y rotación?

### 🚚 Proveedores
- ¿Qué proveedores tienen mayor peso en las ventas?
- ¿Existe dependencia de proveedores clave?

### 🌎 Análisis geográfico
- ¿Qué países generan mayores ventas?
- ¿Dónde se concentra la actividad comercial?

---

## 💡 Principales insights

- 📈 **Fuerte variación en el crecimiento de las ventas** entre períodos.
- 🇺🇸 **USA lidera las ventas**, seguido por Germany y Austria.
- 👥 **Los ingresos presentan una alta concentración en los principales clientes**, evidenciada mediante el análisis **80/20 (Pareto)**.
- 🥤 **Beverages destaca entre las categorías de mayor desempeño**.
- 📦 El portafolio combina **productos de alta rotación y productos de mayor valor**.
- ⚠️ **Produce presenta un menor desempeño relativo**, representando una oportunidad de análisis.

## 📌 Conclusión

Este proyecto demuestra el uso de **SQL + Power Query + Power BI + DAX** para transformar datos transaccionales en información orientada al negocio.

El análisis permite identificar **tendencias, concentración de clientes, mercados relevantes, categorías de alto desempeño y oportunidades de mejora**, mostrando cómo las herramientas de Business Intelligence pueden apoyar la toma de decisiones basada en datos.
